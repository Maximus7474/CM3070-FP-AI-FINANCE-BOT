## Project Architecture

The project has three main components:

* React frontend
* Tauri/Rust desktop backend
* Python AI/RL sidecar

Important architectural fact:

* Tauri starts and manages the Python sidecar.
* React communicates directly with the Python sidecar.
* React does not normally communicate with Python through Tauri/Rust.
* Document any exceptions only if they are present in the source.
