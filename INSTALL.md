# Installation Guide

Quick start for end users: install the app, install Ollama, pull the model, and launch.

> [!WARNING]
> This application is a tool, not financial advice. Recommendations are generated by AI and can be wrong. Always verify with reliable sources before making investment decisions.

## Requirements

- **Windows 10 or 11** (64-bit)
- ~8 GB of free disk space (the AI model alone is several GB)
- An internet connection for the initial download of Ollama and the model

## Step 1 — Install the app

1. Download the installer: `financial-advisor-app_0.1.0_x64-setup.exe`
2. Double-click it and accept the defaults.
3. When the installer finishes, the app is installed — do not launch it yet.

## Step 2 — Install Ollama

Ollama runs the AI model locally on your machine. The app needs its server running on `localhost:11434`.

1. Go to **https://ollama.com/download** and download the Windows installer.
2. Run it and follow the prompts.
3. After installation, Ollama starts automatically in your system tray (the llama icon near the clock). Leave it running.

## Step 3 — Pull the model (required)

The app uses the **`0xroyce/plutus`** model. This step is mandatory — the app cannot download the model itself, and chat/recommendation features will not work until it is done.

1. Open a terminal (press `Win`, type `cmd` or `PowerShell`, press `Enter`).
2. Run:

   ```sh
   ollama pull 0xroyce/plutus
   ```

3. Wait for it to finish. The model is several gigabytes, so the first download can take a while depending on your connection.

## Step 4 — Launch the app

1. Open the **Start menu** and search for **financial-advisor-app** (or find it in the installed apps list).
2. Launch it and wait. The first launch is noticeably slower while the built-in analysis engine extracts and initializes — this is normal.
3. Once loaded, you can get stock recommendations and chat with the AI.

## Troubleshooting

| Symptom | Fix |
| --- | --- |
| App opens but recommendations or chat fail / show an error | Ollama is not running or the model is missing. Check the Ollama tray icon is present, then re-run `ollama pull 0xroyce/plutus`. |
| `ollama` is not recognized as a command | Ollama was not installed or the terminal needs to be reopened after installing. Re-open the terminal and try again. |
| "Pulling manifest" or download stalls | Check your internet connection; the model download can be resumed by re-running `ollama pull 0xroyce/plutus`. |
| Everything loads but responses are slow | The model is still loading into memory on first use, or your machine is underpowered. Wait a few seconds and try again. |
| Backend / sidecar error at startup | The app needs the Ollama server on `http://localhost:11434`. Make sure Ollama is running (tray icon) and the model is pulled, then restart the app. |

## Updating

- **App:** download and run the newest installer — it replaces the previous version.
- **Ollama:** run `ollama update` in a terminal.
- **Model:** run `ollama pull 0xroyce/plutus` again to fetch the latest version.

## Uninstalling

Uninstall **financial-advisor-app** and **Ollama** from *Settings → Apps → Installed apps*. Your downloaded model files can be removed with `ollama rm 0xroyce/plutus` beforehand to free disk space.
